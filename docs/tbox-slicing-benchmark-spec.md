# T-BOX 裁剪独立评测规范

## 目的与冻结原则

以基金用户任务、本体声明和预算契约定义预期，不从裁剪实现反推测试。
先冻结 `tests/fixtures/tbox_slicing_questions.json` 和独立 RDF 契约，再测未修改的实现。
测试适配器可以适配接口，但不得根据实现输出增加答案、删失败题或降低阈值。
本体提供词汇事实，不提供“当前算法选了什么”的答案。

评测不调用在线模型、不加载 A-BOX。测试的是送入模型的 T-BOX 内容，不是最终问答正确率。
`development` 用于诊断；`holdout` 保留为迁移观察组，不据它添加问句特例。
两组均公开，且由同一执行者制作，不能声称是真正盲测或独立专家标注。
当前标注是待领域专家复核的第一版；明确的属性同义表达也可能存在争议。

## 覆盖矩阵

自然语言任务涵盖：

- 类型及继承、管理与托管、正向与反向关系、多跳连接；
- 净值及规模、时间范围及最新记录、业绩及排序；
- 费率、申赎门槛、风险代码、持仓、份额、报告与法规；
- 定义及比较、组合过滤、口语改写、未知需求与含糊输入；
- 10000 / 1800 / 800 字符三种预算，以及独立极小预算契约。

期望类与属性由本体含义人工指定。存在直接与逆向声明时，连接允许二者择一；
例如 `hasNetAssetValueRecord` 与 `recordForFund` 都可支撑基金和净值记录连接。
不要求与当前 BFS 排序相同，不从运行结果生成 gold。
为防止只给名词而没有可操作关系，连接属性也纳入每题覆盖判定。

独立微型 RDF 契约使用不同于业务本体的任意标识符：

1. 过滤、遍历、投影、关系路径、排序、聚合度量、日期、最新、嵌套条件和 OPTIONAL 依赖；
2. 必需属性优于任意字典序的可选邻居；
3. 必需端点优于可选子类，反向路径方向保留；
4. 匿名 some/all/hasValue/cardinality/qualified-cardinality 约束；
5. equivalentClass 约束、inverse/subProperty/property-chain 支撑；
6. 类/属性/三元组/token 预算、显式截断、极小预算与长问题；
7. 实际文本与返回元数据一致、无悬空引用、稳定重复运行；
8. 新增本体标签/定义后无需修改 Python 问句规则。

微型图是测试规范，不是生产代码输出的镜像。属性取名故意与基金词汇无关，
并使用一个非 CNFO 命名空间检查泛化，不能仅为某个测试 IRI 特判。

## 指标

所有自然语言 gold 检查针对**渲染定义行**，不能仅检查候选元数据或问题文本。

- 类召回 / 属性召回：人工必需项在最终定义行中的比例。
- 连接召回：人工等价连接组至少一个定义保留的比例。
- 严格任务覆盖：类、属性、连接全部满足才通过。
- 核心精度：输出中属于 gold 核心及端点/祖先支撑的概念比例。
  其他概念可能仍有帮助，故该指标是上下文杂质代理，不称绝对精确率。
- 压缩率：局部字符数相对完整语义视图；完整视图只作为参照，不当人工 gold。
- 安全性：预算合规、无悬空属性/路径、元数据一致、截断可观测。
- 后置依赖召回与 OWL 保留：独立契约逐条统计。

报告按预算和组别分别展示，禁止只合并出一个“正确率”。
预算不足且显式降级：安全契约可通过，语义覆盖仍失败。
未知任务不要求编造不存在的属性；空白/含糊任务不应大范围扩展本体。
不做任意 OWL 蕴含保持承诺，约束保存只检查声明和支撑公理。

## 迭代与交付

1. 固定用例与 SHA256，保存 baseline 逐题 JSON。
2. 第一轮修复 P0/P1 和匿名 restriction：独立契约优先。
3. 第二轮增强确定性词汇召回、路径排序和语义包预算。
4. 同一冻结集重复测，保存各轮输出、改进/退化题及耗时。
5. 运行相关原有回归；残余失败不得删除，应记录后续方向。
6. 不改本体、不调用付费模型、不自动提交或推送。

P4 在线扩大上下文只在能够可靠检测缺失后另行评估，当前离线指标不能证明它改善答案。
