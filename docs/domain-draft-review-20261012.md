## 必须修订的四题

### P1：private-07 的责任财产主体混淆

证据：V1 题干写“违法基金的财产不足以同时支付投资者民事赔偿和行政罚款、没收违法所得”。私募第六十条规定的是违反条例和基金合同约定、依法应承担相应责任时，“其财产”不足则先承担民事赔偿。第四条同时明确“私募基金财产独立于私募基金管理人、私募基金托管人的固有财产”。第六十条并不把所有管理人、托管人等违法责任当然转化为基金财产的支付责任。

影响：参考答案复述赔偿优先原则本身基本正确，但题干可能诱导把投资者共同基金财产用于支付他人行政责任。缺少责任主体，不能无条件确认题设中的财产可支付这些责任。

建议新题：“某责任主体违反本条例规定和基金合同约定，依法同时承担民事赔偿责任及相应罚款或没收违法所得，其可用于承担这些责任的财产不足以同时支付，应优先承担哪项责任？”保留第六十条为目标即可；参考答案明确同一责任主体的责任财产。若保留“基金财产是否可支付管理人罚款”的问题，则必须新增第四条证据并重写题意、oracle、参考答案。

### P1：holdout-sales-02 把一般经营年限替代基金销售业务年限

证据：V2 题干为“独立销售机构连续经营已满三个完整会计年度”；销售第三十七条第一款第一项为“连续开展基金销售业务3个完整会计年度以上”。reference 却直接断言题设达到这几项条件。该项还要求“最近一个会计年度”日均保有量，题干仅写“上一年度”。

影响：机构经营满三年并不必然意味着连续开展基金销售业务满三个完整会计年度；若没有补充事实，不能肯定年限项满足。最近年度与会计年度也应对齐。

建议新题明确“已连续开展基金销售业务满三个完整会计年度，最近一个会计年度基金销售日均保有量恰好100亿元”。人员明确为“取得基金从业资格的人员5名”。保留第三十七条及其单组目标；保留不据此确认所有设立条件齐备的限制。

### P1：holdout-disclosure-04 参考答案压缩逻辑条件，可能把 OR 写成 AND

证据：信披第二十三条原文为“可能对基金份额价格产生误导性影响或者引起较大波动，以及可能损害基金份额持有人权益的”。V2 reference 改为“可能误导价格、引起较大波动并可能损害持有人的传播消息”，没有保留前两项之间的“或者”；source_notes 又压缩为“知悉误导消息立即澄清”。题干只给“可能误导价格并损害持有人”，未给“引起较大波动”。

影响：如果参考答案被用作语义判分标准，逗号列表与“并”可被理解为三项同时满足，错误缩窄原文触发条件；source_notes 则有反向过度简化风险。题干所述情形可落入原文，错误主要在参考表达。

建议把 reference 的触发部分保留为原文条件：“消息可能对基金份额价格产生误导性影响或者引起较大波动，以及可能损害基金份额持有人权益的”，然后说明知悉后立即澄清和报告。不要自行重排逻辑连接词或增加必须发生较大波动的要求。保留第二十二条、第二十三条两组 AND。

### P1：holdout-challenge-02 在历史时点误称旧版本已废止

证据：V2 题干要求“截至2020年9月30日”，同时要求“不要用已废止旧版本”。销售第六十三条规定本办法自 2020-10-01 施行，旧《证券投资基金销售管理办法》（第91号令）“同时废止”。因此就题目指定的 2020-09-30 时点，该条所指同时废止事件尚未发生。

影响：该负控期待 unresolved 的主要理由正确，但题干夹带了不对应查询时点的旧法状态。不能让拒绝回退的接口测试传递错误历史法律状态。

建议把末句改为“不要用其他版本或其他文件替代”，或明确“不接受该时点适用的其他版本替代”。保留 doc_ids、as_of、unresolved、空目标及空组；在 reference 中区分“文本已公布”与“所请求版本当日尚未施行”。

## 版本、范围和测量限制

1. 两套题均明确请求固定入库版本，避免把旧文本称为现行法律。这是封闭语料阅读任务，不能包装成 2026 年现行适用法已核验。
2. 信披2020修订的 `effective_from: null` 合理保留了元数据未知状态；2019-09-01是原办法施行日期，不能据此回填2020修订。若日后补修订施行证据，需要独立版本核验及数据变更记录。
3. challenge 主干逻辑是允许范围、版本或时点限制；unresolved 意味受限请求无法给出所需版本证据，不宣称相关实体法在外部世界不存在。
4. 题干普遍包含法名和版本，若评价固定语料检索，这是明确需求；若声称覆盖真实无提示业务咨询，则精确门槛、条号和答案结构会降低任务难度。应分别统计直接定位、引导式合规、自然业务和接口契约。
5. 多条 AND 衡量证据完整性，不证明系统逐项解释正确，更不能把文章命中率当业务准确率。
